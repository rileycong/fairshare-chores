# FairShare Chores

A mobile-friendly, installable web app for 2–4 roommates that fairly rotates household chores by completed effort points.

## MVP features

- Fair recurring-chore assignment using fixed small, medium, and large effort points.
- Accepted chore swaps, overdue tracking, and a full completion history.
- Per-chore WhatsApp and web-push reminders; WhatsApp replies can mark assigned chores complete.
- An AI prompt box for assignment explanations and confirmed chore or swap actions.
